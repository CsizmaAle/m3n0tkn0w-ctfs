## **Recognition Pattern**
- "Does not decompress cleanly" → the file was obfuscated before transfer, probably XOR
- HTTP traffic with a file download → File → Export Objects → HTTP to pull it out
- The extracted "gzip" had the wrong header → the data's been XOR'd, not just damaged
- One byte repeating a lot in the hex (`4a` all over) → likely the XOR key, since null bytes XOR back to the key itself
- Hints about both XOR and gzip in the traffic → XOR first to deobfuscate, then gunzip

## **Approach and Methodology**
### **Initial Analysis**
Ran `binwalk` and `cat` to check for hidden messages, then opened the file in Wireshark. I knew I'd use Wireshark since it was a networking CTF and the file was a `.pcap`.  

### **Steps Taken**
In Wireshark I realized it was about downloading a file over HTTP, and I also found some information about XOR and gzip. I exported the object (File → Export Objects → HTTP) and opened it with `xxd`:

From Wireshark I knew it was supposed to be a gzip, so I changed the header to `1f8b 0800` (using hexedit), but couldn't unarchive it no matter what I did. So I approached it with XOR instead.  

I went to CyberChef and put together a full recipe that gave me the flag. I used the key `4a` because it appeared a lot in the original file (null bytes XOR'd with the key produce the key itself).  

## **Solution and Flag Retrieval**
*Final Exploit / Command Used:* CyberChef recipe — XOR with key `4a` → From Hex → Gunzip → **Bake!**  

![CyberChef recipe recovering the flag after XOR and gunzip](Unh1dden_1.png)

## **Lessons Learned**
- Repeating bytes in XOR'd data give away the key — the `4a4a4a4a` runs meant the key was `0x4a`, because null bytes in the original XOR to the key itself. That's the weakness of single-byte XOR.
- CyberChef chained the whole thing: XOR key `4a` → From Hex → Gunzip → flag, all off the "Bake!" button. Worth saving the recipe.
- My mistake first: I tried forcing the gzip header back to `1f8b 0800` in hexedit and it never unzipped. The wrong header meant the data was transformed, not damaged, so patching it was pointless — XOR was the actual fix.
