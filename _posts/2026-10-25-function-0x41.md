**Challenge Description**: This field device speaks a vendor extension on top of Modbus/TCP, function code `0x41`. The integrator who documented it is long gone and the manual went with them.  

Mirror 1: `18.215.143.250:1502`  
Mirror 2: `18.145.136.91:1502`  

**Files provided**:  server.py  

## **Environment and Tools** 
**Operating System**:  Kali Linux (Parallels)  
**Tools/ Software**:  pwntools, netcat  
**Programming Languages (if any)**:  bash, python  

## **Recognition Pattern**
- The source (server.py) is provided, so read it to find the custom function code and how it checks the answer
- Custom function code 0x41 takes a seed and a guess, and returns the flag when guess == transform(seed)
- The transform is in the source => just replicate it, the only extra work is wrapping it in a proper Modbus/TCP frame

## **Approach and Methodology**
The first thing i did was open the server.py file and read it in order to find the vulnerability.

```bash
import socketserver
import struct

FLAG = b"rstcon{REDACTED}"
UNIT_ID = 0x01
CUSTOM_FC = 0x41

BREADCRUMB = [ord('0'), ord('x'), ord('4'), ord('1')]

def transform(seed: int) -> int:

    return (((seed ^ 0x1F3D) * 0x0101) + 0x2027) & 0xFFFF

def mbap(tid, proto, unit, pdu):
    return struct.pack(">HHHB", tid, proto, len(pdu) + 1, unit) + pdu

def exception(fc, code):
    return struct.pack(">BB", fc | 0x80, code)

def handle_pdu(pdu: bytes) -> bytes:
    fc = pdu[0]

    if fc == 0x03:
        if len(pdu) < 5:
            return exception(fc, 0x03)
        addr, qty = struct.unpack(">HH", pdu[1:5])
        vals = []
        for i in range(qty):
            r = addr + i
            vals.append(BREADCRUMB[r] if 0 <= r < len(BREADCRUMB) else 0)
        body = b"".join(struct.pack(">H", v) for v in vals)
        return struct.pack(">BB", 0x03, len(body)) + body

    if fc == CUSTOM_FC:
        if len(pdu) < 5:
            return exception(fc, 0x03)
        seed, guess = struct.unpack(">HH", pdu[1:5])
        if guess == transform(seed):
            return struct.pack(">BB", CUSTOM_FC, 0x00) + FLAG
        return struct.pack(">BB", CUSTOM_FC, 0x01)

    return exception(fc, 0x01)

class Handler(socketserver.BaseRequestHandler):
    def handle(self):
        buf = b""
        while True:
            chunk = self.request.recv(1024)
            if not chunk:
                break
            buf += chunk

            while len(buf) >= 7:
                tid, proto, length, unit = struct.unpack(">HHHB", buf[:7])
                if len(buf) < 6 + length:
                    break
                pdu = buf[7:6 + length]
                buf = buf[6 + length:]
                resp_pdu = handle_pdu(pdu)
                self.request.sendall(mbap(tid, proto, unit, resp_pdu))

class Server(socketserver.ThreadingTCPServer):
    allow_reuse_address = True
    daemon_threads = True

if __name__ == "__main__":
    HOST, PORT = "0.0.0.0", 502
    print(f"[*] Function 0x41 device listening on {HOST}:{PORT}")
    Server((HOST, PORT), Handler).serve_forever()
                                                                  
```

A few interesting elements can be found in the code: 
	- the breadcrumbs are 0x41, which are an interesting hint for trying to get the flag without the source code, as it points towards the function (vulnerability)
	- the server asks the user to send a seed and a guess and if they are equal the server returns the flag, so this is the attack surface.
Since the transform function is visible, there is no need to do much, just apply it to a random seed and send them together to the server. However, that's not enough. There is the message format that needs to be tackled. 

In short, it's a custom protocol built over Modbus/TCP, that requires the following information: tid(2) proto(2) length(2) unit(1).

So the last thing to do now was to write the python script:
```python3
#!/usr/bin/env python3

from pwn import *
import socket, struct

#18.215.143.250:1502
conn=remote("18.215.143.250", 1502)

  
  
# same function as the server
def transform(seed):
	return (((seed ^ 0x1F3D) * 0x0101) + 0x2027) & 0xFFFF

seed = 0
guess = transform(seed) # compute the matching answer

  
# building the packet that will be sent
pdu = struct.pack(">BHH", 0x41, seed, guess) # fc, seed, guess (5 bytes)
frame = struct.pack(">HHHB", 1, 0, len(pdu)+1, 0x01) + pdu # tid, proto, length, unit

  
# send the packet and read the output
conn.sendline(frame)

#important! needs to catch everything before the connection closes
print(conn.recvall(timeout=2).decode(errors="ignore"))

conn.close()
```

Afterwards, the last thing that needed to be done before running the script was to change its permissions: chmod +x solver.py

## **Lessons Learned**
- some challenges might ask for protocol-specific packets (here a Modbus/TCP MBAP header around the PDU)
- when the source is given, replicating the check (transform) is faster than attacking it blind
