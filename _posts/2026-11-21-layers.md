## **Recognition Pattern**
- the title implies multiple encryption/encoding algorithms being applied
- each layer looks like a different encoding: base64 shape, then hex (0-9 a-f), then scrambled letters with the {} intact (rot13/caesar)

## **Approach and Methodology**
### **Initial Analysis**
On first reading the challenge it was obvious it was similar to what i've done before, a string encrypted using multiple algorithms, i just needed to figure out the algorithms. 

### **Steps Taken**
From the shape of the ciphertext i assumed it was base64 or something similar like b16 or b32. 

I opened CyberChef and applied the base64 recipe. Next up looked similar to hex having values 0-9 and a-f, so i applied over the base64 the hex decipher recipe. 

The last layer looked like scrambled letters, like in the wrong order, but the {} looked right. So i figured out it could be caesar or rot13. For sure not rot 47 as the {} were not scrambled. So i added rot13 and the flag was readable.


## **Solution and Flag Retrieval**
Final Exploit / Command Used: bake! (From Base64 → From Hex → ROT13)  
![CyberChef decoding the three layers to the flag](Layers_1.png)

## **Lessons Learned**
- when a string is wrapped in several encodings, peel them one layer at a time by the shape of each output (base64 → hex → rot13)
- rot13 vs rot47: rot47 would also scramble the {} braces, so intact braces point to rot13/caesar
