## **Recognition Pattern**
- "Timing is suspiciously structured" + "payloads look harmless" + "header fields are ordinary" → the data's in the timing between packets, not the content
- ICMP where payloads and headers look normal → a covert timing channel, so I measure the delta between request/reply pairs
- Two different ICMP identifiers (`0x1337` vs `0x2000`) → filter by identifier to split the real signal from the noise
- Deltas that land in the ASCII range after transforming → each timing gap encodes one character

## **Approach and Methodology**
### **Initial Analysis**
After downloading the file I opened it in Wireshark and looked at the packets, trying to find something useful. I didn't know at this point that I'd made a mistake that would cost me later: not reading the challenge description.  

### **Steps Taken**
The key to this CTF was reading the description and keeping in mind that the issue with the `.pcap` was the timing of the packets — the time between each request-response. To solve it, I filtered out the noise packets (`0x2000`) and saved the file as `good.pcap`. The filter applied was:
```
icmp.ident == 0x1337
```

Then I wrote a Python script to extract and calculate the delta between request-response and transform it into text. A few issues came up while writing this: I needed to learn how to handle `.pcap` files; using `int(value*1000)` to keep the first 3 digits loses data due to trimming (0.105999999 becomes 105, not 106 as needed); and my initial code calculated all deltas, when I only needed the ones inside the same request-reply pair.

```python
#!/usr/bin/env python3
from scapy.all import rdpcap
import sys

def read_delta_times(pcap_file):
    packets = rdpcap(pcap_file)
    deltas = []
    for i in range(1, len(packets)):
        delta = float(packets[i].time) - float(packets[i-1].time)
        deltas.append(delta)
    deltas = deltas[::2]
    print("delta was processed")
    return deltas

def truncate_delta(deltas):
    numbers = []
    for i in deltas:
        temp = round(i * 1000)
        numbers.append(temp)
    return numbers

def int_to_ascii(numbers):
    text = []
    for i in numbers:
        text.append(chr(i - 20))
    return text

def flag_reveal(text):
    flag = ""
    for i in text:
        flag = flag + i
    return flag

if __name__ == "__main__":
    deltas = read_delta_times(sys.argv[1])
    numbers = truncate_delta(deltas)
    text = int_to_ascii(numbers)
    flag = flag_reveal(text)
    for i in range(0, len(deltas)):
        print(str(deltas[i]) + " and " + str(numbers[i]))
    print(flag)
```

## **Lessons Learned**
- Read the description carefully before diving in — this one literally said "timing is suspiciously structured", and skipping it cost me hours chasing the `0x2000` noise packets. The description was part of the challenge.
- The data was in the gaps between packets, not the packets themselves — a covert timing channel, the hardest kind to spot since everything looks normal except the timing.
- scapy (`from scapy.all import rdpcap`) is what let me script it: `rdpcap()` loads the packets and `packet.time` gives each timestamp, which Wireshark alone wasn't going to get me.
- Precision bit me — `int(0.105999 * 1000)` gives 105 but `round(...)` gives 106, so for the timing deltas I had to use `round()`, not `int()`.
- I only needed the deltas inside each request-reply pair (`deltas[::2]`), not between every packet. Filtering `icmp.ident == 0x1337` and saving that as its own pcap is what isolated the real signal and kept the script simple.
