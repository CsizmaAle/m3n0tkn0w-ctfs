## **Recognition Pattern**
- A forensics "evidence" archive of mixed files (txt / pdf / png / jpg) → check each one, but images are the classic place to hide an appended archive
- `cat` on the JPEG showing `PK…secret_note.txt` / `readme.txt` at the end → a whole zip is appended after the image's real data

## **Approach and Methodology**
### **Initial Analysis**
I was handed a zip of "evidence", so I extracted it and went through each file. Text and PDF are worth a quick look, but images are usually where something's hidden, so that's where I focused.

### **Steps Taken**
1. Ran `binwalk` and `file` on the archive, then extracted it:

```bash
7z x evidence-batch-1.zip
```

That gave four files: `notes.txt`, `invoice.pdf`, `profile.png`, `holiday_photo.jpg`.

2. `cat` on `invoice.pdf` and `notes.txt` — nothing interesting.

3. `cat holiday_photo.jpg` — at the end I could see `PK` signatures and the filenames `secret_note.txt` and `readme.txt`, so a zip is tacked onto the end of the JPEG:

```
PK..\@..b2;;secret_note.txt
...readme.txt
...secret_note.txt PK ...
```

4. `binwalk holiday_photo.jpg` confirmed it — a zip archive embedded past the image data:

```
DECIMAL   HEXADECIMAL   DESCRIPTION
--------------------------------------------------------------------------------
0         0x0           Zip archive data, ... name: secret_note.txt
104       0x68          Zip archive data, ... name: readme.txt
303       0x12F         End of Zip archive, footer length: 22
```

5. Extracted the hidden files:

```bash
binwalk -e holiday_photo.jpg
```

## **Solution and Flag Retrieval**
*Final Exploit / Command Used:*

```bash
cat secret_note.txt
```

### **Alternative Approaches (if applicable)**
Since it's just a zip appended to the JPEG, `7z x holiday_photo.jpg` (or `unzip holiday_photo.jpg`) pulls the same two files out directly, and `foremost` would carve them too.

## **Lessons Learned**
- Files can carry other files appended after their real end — the viewer ignores the extra bytes, but `cat` and `binwalk` show the `PK` zip signature and the hidden filenames.
- When an image feels too big or `cat` shows `PK…something.txt`, reach for `binwalk -e` (or just unzip the image).
- Check every file in a forensics drop, but weight the images — that's where this one hid the note.
